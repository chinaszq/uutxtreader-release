# 何扰（HeRao）发行页

**基本简介**

何扰是一款以本地 **TXT 纯文本** 为主力场景的阅读工具（亦支持部分 EPUB），由 **何扰软件工作室（HeRao Software Studio）** 开发与维护。  
官网：[https://herao.uurj.com](https://herao.uurj.com)

**新安装即送 7 天 Pro 试用；试用结束后，基础功能仍可永久免费使用。**

**功能特色**

1. 无书城、无广告，专注本地阅读
2. 自研中文编码识别，减少常见乱码
3. 多模式目录解析（可自动竞优，需 Pro / 试用），适应混乱或不规范标题
4. 时空回溯：跳转章节 / 搜索后可快速返回原位
5. 自动阅读，支持按阅读习惯智能初始化滚动速度
6. 多引擎听书（系统语音、云 TTS、Sherpa 本地等；ZipVoice 音色克隆需 Pro / 试用）
7. 全文搜索：精确匹配始终可用；通配符模糊与正则需 Pro / 试用
8. 支持本机导入、WiFi 传书等方式导入书籍
